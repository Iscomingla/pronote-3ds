# notApro — Quick Start

## Build

```bash
make clean && make
# → notApro.3dsx
```

## Install

Copy `notApro.3dsx` → `/3ds/notApro.3dsx` on your SD card, launch from Homebrew Launcher.

## Login Flow

1. Open Pronote on your phone/computer → generate a QR code (Settings → QR Login)
2. On 3DS: navigate to **Jeton** field → press **A** → point camera at QR code
3. Username and jeton are filled automatically
4. Navigate to **PIN** field → press **A** → enter 4-digit PIN from Pronote
5. Press **X** to login

## Controls

| Button | Action |
|--------|--------|
| UP/DOWN | Navigate fields |
| A | Edit / Scan QR |
| Y | Clear field |
| X | Login |
| B (in scanner) | Cancel scan |
| START | Exit |
