# Instructions for Claude AI

## Instructions update
Instructions may be updated, before making a change, check them

## Push
Always push to a new branch and create a PR, never push to main.
The PRs are often merged, check if the PR isn't closed before adding commits

## Co-working
Multiple changes can be made without you know, check for every task if files you have are up to date.

## Fixes
When you have to fix something, add it to [TOFIX.md], then fix, and then remove from [TOFIX.md] (helps cuz prompts are often interupted).

## To-do list
You can add every thing to do in [TODO.md]; update it regularly
